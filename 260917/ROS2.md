## 예제 문제

- $k_p = 2, k_i = 1, k_d = 0.05, dt = 0.1 s$
- 이전 적분 누적 = 0.4, 이전 오차 = 2 현재 오차 = 1, 제어출력한계 = +-1  

- $P = K_p \times 현재 오차 = 2$
- $I = K_i \times (이전 적분 누적 + 현재 오차 \times dt) = 0.5$
- $D = (현재 오차 - 이전 오차) \div dt = -10$
- $k_d \times D = -0.5$
- $A = I = 0.4 + 1 \times 0.1 =0.5$
- $u = P + I + D = 2 + 0.5 - 0.5 = 2.0$
- (문제 1) 제어출력한계 = +-1, 최종 제어 출력 u = 2.0이므로 실제 출력 : 1
- (문제 2) D항의 부호가 음수인 이유 : 오차 값이 2에서 1로 감소하였으므로 음의 부호를 갖는다.
