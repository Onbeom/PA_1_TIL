## 문제와 해결
| 문제 | 원인 | 해결 |
|---|---|---|
| 팔 카메라로 잰 위치가 틀림 | 시뮬레이션 내부값 가정(fx 424), 실측은 fx 865 | 실측 보정 파일 |
| 영상이 뒤집혀 들어옴 | 카메라가 거꾸로 장착됨 | 180° 돌려 발행, 주점도 함께 옮김 |
| 15.3Hz로 프레임이 빠짐 | best effort 전송 손실 + 캡처 버퍼 1장 | 공유 메모리 키움 · 버퍼 2장 → 30.6Hz, stamp 나이 p99 13ms |
| IMU 방향이 모델과 다름 | 보드가 90° 돌아 장착 | `imu_link` yaw −90° |
| joint1이 정면에서 약 ±3.2rad, 켤 때마다 부호가 바뀜 | 혼이 180° 돌아 끼워져 정면이 tick 경계 | Issue로 알림 → 혼 재조립 |
| 태그 읽기 느림 | 통신이 아니라 계산(축소 영상 검색 48.4ms 등) | 검색 단축 |

## 배운 점
- 시뮬레이션 카메라 내부값을 실물에 쓰면 거리가 크게 틀림 → 실물은 반드시 보정
- 영상을 180° 돌리면 주점도 $c_x' = W - 1 - c_x$, $c_y' = H - 1 - c_y$로 옮겨야 함 ([261029](../261029/ROS2.md) 크롭·리사이즈 때 $K$를 바꾸는 것과 같은 이야기)
- 느리면 먼저 원인이 전송인지 계산인지 가름
