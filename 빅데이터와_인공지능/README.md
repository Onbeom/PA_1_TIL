## 근거와 보완 계획

- [현재 참고자료](../ref/빅데이터와_인공지능/빅데이터와_인공지능_대화내용_정리.md)는 원본 대화 내보내기나 강의 전사본이 아니다. 개념 보충과 과거에 확인되었다고 전달된 기록을 구분한다.
- 관련 질문일은 2025-10-22 KST이며, 질문일·파일명 날짜·이번 정리일을 구분한다.
- 우선 대조할 자료는 Ch01·Ch03·Ch04·Ch05 PDF다. Ch02 제공 여부는 확인되지 않았다.
- 녹음은 2025-09-17 두 개, 09-24·10-01·10-15 각 한 개가 과거 목록에 있다. 실제 파일은 아직 없다.
- 당시 제공되었다고 기록된 `빅데이터_수업요약.txt`의 본문과 관련 대화 원문도 아직 없다.
- 자료가 추가되면 날짜·장 대응, 정의·예제·교수 설명을 확인하고 기존 TIL을 보완한다. 실습 결과와 확인되지 않은 인공지능 알고리즘 내용을 임의로 추가하지 않는다.
- 참고자료는 `ref/빅데이터와_인공지능/`에 분류한다. 로컬 자료 링크는 해당 파일이 있는 환경에서 사용할 수 있다.
