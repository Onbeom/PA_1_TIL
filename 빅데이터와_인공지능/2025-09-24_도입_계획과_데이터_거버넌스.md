## 학습 내용

빅데이터 도입은 저장 장비나 분석 도구를 먼저 선정하는 일만으로 완성되지 않는다. 해결하려는 문제, 필요한 데이터, 데이터 확보 가능성, 활용 담당자와 운영 방법을 함께 계획해야 한다. 분석 결과가 의사결정에 실제로 쓰일 수 있는지도 검토해야 한다.

데이터 거버넌스는 데이터에 관한 책임, 기준과 관리 체계를 정하는 관점이다. 예를 들어 어떤 데이터가 기준 정보인지, 누구에게 수정 권한이 있는지, 품질 문제를 누가 해결하는지, 얼마나 보관할지를 정한다. 이것은 특정 데이터베이스 제품의 기능만을 뜻하지 않는다.

보안과 프라이버시는 관련되지만 같은 문제는 아니다.

| 구분 | 주요 관심 |
| --- | --- |
| 데이터 품질 | 정확성·완전성·일관성 등 분석에 필요한 신뢰성 |
| 거버넌스 | 책임 주체, 관리 기준, 데이터 정의와 운영 절차 |
| 보안 | 비인가 접근·변경·유출 등으로부터 데이터와 시스템 보호 |
| 프라이버시 | 개인에 관한 정보를 어떤 목적과 범위로 수집·이용하는지 |

접근을 안전하게 제한하더라도 필요 이상으로 개인정보를 수집하면 프라이버시 문제는 남을 수 있다. 반대로 분석 목표를 명확히 해도 권한 관리가 부실하면 데이터가 유출될 수 있다. 이 문서는 법률 판단이 아니라 개념의 차이를 정리한다.

## 학습한 점

- 도입 계획에는 기술, 데이터, 사람과 운영 기준이 함께 필요하다.
- 좋은 분석 모델도 품질이 낮거나 정의가 다른 데이터에는 영향을 받는다.
- 보안과 프라이버시를 별도 관점으로 점검한다.
