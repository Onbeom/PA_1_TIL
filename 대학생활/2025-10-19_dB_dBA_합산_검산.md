## 질문의 출발점

이전 과제 풀이에서 빠진 비가중 전체 음압 수준을 요청했고, dB와 dBA를 계산할 때 선형값으로 바꾸어 합산하는 이유를 질문했다.

## 사용한 데이터

63~8000 Hz의 8개 밴드 수준은 `85, 90, 98, 100, 96, 92, 80, 78 dB`다. 밴드별 A보정값은 [10월 2일 기록](2025-10-02_소음_A보정_계산.md)에 정리했다.

## 학습 정리

$$L_{total}=10\log_{10}\left(\sum_i10^{L_i/10}\right)$$

음압 수준의 정의는 `20log10(p/p_ref)`이지만, 비상관 성분의 합산에서는 제곱 음압에 대응하는 에너지 비 `10^(L/10)`를 합산한다. 그래서 전체 수준 계산에 10log를 사용한다.

이 공식을 아무 위상관계의 음압 신호 합산에 그대로 쓰는 것은 아니다. 여기서는 과제의 서로 다른 밴드를 에너지 합산하는 계산을 정리했다.

## 이번 정리에서 재검산한 결과

| 구분 | 과거 답변에서 검색된 값 | 입력 데이터 재계산 |
| --- | ---: | ---: |
| 비가중 전체 Lp | 약 103.65 dB | **103.6838 dB** |
| A가중 전체 LA | 약 100.8 dBA | **100.7961 dBA** |

입력된 8개 밴드로 계산하면 비가중 결과는 소수 둘째 자리에서 **103.68 dB**다. 과거 답변의 103.65 dB와는 차이가 있으므로 본 TIL에서는 재계산값을 사용한다. 차이의 원인은 원본 계산 과정이 없어 확정하지 않는다.

## 재현용 코드

```python
from math import log10

lp = [85, 90, 98, 100, 96, 92, 80, 78]
a = [-26.2, -16.1, -8.2, -3.2, 0, 1.2, 1, -1.1]

total = 10 * log10(sum(10 ** (x / 10) for x in lp))
a_total = 10 * log10(sum(10 ** ((x + y) / 10)
                           for x, y in zip(lp, a)))
print(total, a_total)
```

## 오늘의 핵심

dB는 로그 표현이므로 실제 합산은 선형 에너지 비로 수행하고, 마지막에 로그로 변환한다.
