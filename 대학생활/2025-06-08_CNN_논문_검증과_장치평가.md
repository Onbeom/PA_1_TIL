## 학습 정리

데이터 전처리는 사용했다는 표현만으로 충분하지 않다. 정규화 방법과 데이터 분할 기준을 남겨야 같은 실험을 다시 구성할 수 있다. 층화 분할은 클래스 비율을 고려하는 방법이지만, 비슷한 이미지가 학습·평가 집합에 나뉘어 들어가는 문제까지 자동으로 해결하지는 않는다.

혼동행렬과 precision·recall·F1은 같은 클래스 순서와 같은 데이터 집합을 기준으로 작성해야 한다. 지표의 평균 방식과 표의 기준이 일치하는지 확인하는 것이 중요하다.

장치 추론속도를 비교할 때는 입력 크기, batch size, 수치 정밀도, 실행 환경 및 측정 범위를 남겨야 한다. 모델 추론만 측정했는지, 영상 전처리까지 포함했는지도 구분해야 한다.

Pruning과 quantization은 경량화를 검토하는 기술로 다루되, 실제 적용·측정 기록이 없는 상태에서 성능 향상을 연구 결과로 확정하지 않는다.

## 다시 확인할 부분

데이터 수, 분할 비율, 원본 코드, 클래스별 지표, 실제 장치 측정 로그가 없다. 검색에서 확인되지 않은 정확도·FPS·모델 크기를 새로 채워 넣지 않는다.
