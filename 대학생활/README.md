# 대학생활 TIL — 기계시스템공학

기계시스템공학 전공으로 질문한 기술·해석·실험 데이터 대화를 날짜별로 정리했다. 학과 홍보물, 교양 과제, 일반 대학생활과 투자 대화는 제외했다. 새싹보리 영상 분석은 전공 연구로 확인된 두 대화만 포함했다.

## 작성 기준

- 정리일은 2026-10-15이며 파일 날짜는 검색으로 확인된 최초 질문일(Asia/Seoul)이다.
- 대화 검색 결과의 사용자 조건과 당시 답변을 구분했다. 원문 그대로의 인용이 아니라 학습용 재구성이다.
- 검색 가능한 기록에 기반한 1차 정리이며, 전체 과거 채팅을 빠짐없이 조사한 결과는 아니다.
- 원본 첨부파일·전체 대화·코드·실험 로그를 확보하지 못한 항목은 각 파일에 표시했다.
- 기본 수식 설명은 복습용 정리다. 당시 답변에서 제안한 조건을 실측값이나 확정 원인으로 바꾸지 않았다.
- 직접 계산 가능한 단위 변환과 dB 합산만 검산했다. 성능표·CFD 결과를 새로 만들어 넣지 않았다.

## 검산 과정에서 반영한 수정

유동해석과 열교환기는 개념 중심으로 축약했고 상세 해석 결과표·전체 과제 풀이를 생략했다.

1. `0.01 / 0.03 kg/s`는 `36 / 108 kg/h`다. 당시 변경한 `28.2489 / 84.7467 kg/h`는 같은 유량의 단위 변환이 아니다.
2. 확인된 소음 밴드 데이터의 비가중 합산은 `103.6838 dB`다. 과거 답변에 검색된 `103.65 dB`를 그대로 사용하지 않았다.
3. NACA0012의 높은 CL 원인과 Y+ 적합성은 원본 해석 조건 없이 확정하지 않았다.
