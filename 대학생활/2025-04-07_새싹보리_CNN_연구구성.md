## 질문의 출발점

기계공학 전공 연구로 새싹보리 이미지에서 생육단계를 분류하는 발표논문을 작성했다. VGG16·ResNet50·EfficientNet-B0를 비교하고, 일반적인 교과서 설명보다 연구 조건과 결과를 중심으로 3~4쪽에 정리하려 했다.

- 데이터셋, 촬영 조건, 학습 조건, 성능표와 결론을 구성하는 대화가 있었다.

## 학습 정리

모델 비교의 핵심은 같은 평가 조건에서 어떤 차이가 발생했는지 설명하는 것이다. 데이터 분할이나 전처리가 다르면 모델 구조의 효과와 실험 조건의 효과가 섞인다. 따라서 비교표에는 모델 이름뿐 아니라 데이터 분할, 입력 크기, 전이학습 여부와 평가 기준을 함께 남겨야 한다.

기계시스템에 연결하는 연구에서는 분류 정확도 외에 실제 장치에서 처리할 수 있는지도 설명해야 한다. 다만 당시 장치의 성능을 직접 측정했다는 근거가 없으므로 추론속도나 현장 적용 성능을 결과로 추가하지 않는다.
