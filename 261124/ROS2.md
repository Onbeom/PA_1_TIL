# 2026-11-24 — Attention 스케일링과 여러 헤드가 필요한 이유

학습일 2026-11-24, 정리일 2026-11-25. [23일 TIL](../261123/ROS2.md)에서 배운 Attention을 질문 중심으로 복습했다. 계산 예시를 다시 풀기보다 스케일링·마스크·여러 헤드의 역할과 VLA 적용을 정리했다.

## 왜 √d_k로 나눌까?

정확히는 Key 차원 d_k 자체가 아니라 그 제곱근으로 나눈다.

$$S=\frac{QK^T}{\sqrt{d_k}}$$

내적은 성분별 곱을 더하므로 차원이 커질수록 점수의 크기도 커지기 쉽다. 성분들이 서로 독립이고 평균 0·분산 1이라고 가정하면 내적의 분산은 d_k다. √d_k로 나눠 분산을 1로 맞추면 차원 때문에 점수가 과도하게 커지는 것을 줄일 수 있다.

Softmax에 큰 점수 차이가 들어가면 한쪽 가중치가 거의 1이 된다. 예를 들어 `[1,0]`은 약 `[0.731,0.269]`, `[10,0]`은 약 `[0.99995,0.00005]`다. 너무 몰리면 기울기가 작아져 학습이 어려워질 수 있다. 스케일링은 관련성을 없애는 것이 아니라 점수의 크기를 조절하는 과정이다.

## Causal Attention은 학습 때 미래 정답을 가린다

자기회귀 모델은 앞선 토큰으로 다음 토큰을 예측한다. 학습 시 전체 문장을 넣어 여러 위치를 병렬 처리하더라도, 각 위치가 다음에 올 정답을 직접 참고해서는 안 된다. 마스크로 미래 위치를 가려 실제 생성 때와 같은 조건을 만든다.

행을 Query 위치, 열을 Key 위치라고 하면:

$$M_{ij}=\begin{cases}0&j\le i\\-\infty&j>i\end{cases}$$

$$A=\operatorname{softmax}(S+M),\qquad O=AV$$

처리 순서는 **점수 계산·스케일링 → 마스크 더하기 → 행별 Softmax → Value 가중합**이다. 미래 위치는 지수화하면 0이 되어 가중합에 들어가지 않는다. 허용된 위치의 가중치 합은 1이다. Softmax 뒤 가중치를 단순히 0으로 지우면 합이 1로 유지되지 않으므로, 표준적으로는 Softmax 전에 마스크를 적용한다.

이는 모델이 참고할 입력을 제한하는 방법이지, 관측 오류나 로봇의 위험한 행동을 직접 차단하는 실행 검사는 아니다.

## Multi-Head Attention이 필요한 이유

Single-Head도 모든 허용 위치의 정보를 참고할 수 있다. 다만 각 Query에 대해 하나의 가중치 분포로 Value를 섞는다. 여러 관계를 하나의 가중합에 담으면 서로 다른 단서가 섞여 구별하기 어려워질 수 있다.

Multi-Head는 같은 입력을 **서로 다른 학습 행렬로 투영**해 관계를 병렬로 계산한다.

$$Q_i=XW_i^Q,\quad K_i=XW_i^K,\quad V_i=XW_i^V$$

$$H_i=\operatorname{softmax}\left(\frac{Q_iK_i^T}{\sqrt{d_k}}+M\right)V_i$$

$$Y=\operatorname{Concat}(H_1,\ldots,H_h)W^O$$

같은 문장에서도 물체와 색의 관계, 물체와 장소의 관계를 서로 다른 비중으로 표현할 수 있다. 헤드에 담당 의미를 미리 배정하는 것은 아니며, 학습된 역할이 반드시 깔끔하게 나뉘는 것도 아니다.

### 차원을 나눈다는 말에서 헷갈린 부분

토큰 벡터가 512차원이고 헤드가 8개라면, 일반적인 구성에서 각 헤드의 Q·K·V는 64차원이다. 그렇다고 입력의 앞 64개 숫자만 헤드 1에 주는 것은 아니다. 각 투영 행렬은 입력 512차원 전체를 조합해 64차원 표현을 만든다.

```text
토큰마다 512차원
 → 8개 헤드가 각각 64차원으로 투영·Attention
 → 출력들을 이어 붙여 512차원
 → Wᴼ로 변환
```

핵심은 병렬 계산 자체보다 **서로 다른 표현 공간에서 여러 관계를 포착하고 결합하는 것**이다. 헤드 결과는 고정 순서로 연결하며, FFN은 이후 각 위치의 특징을 가공한다. FFN이 헤드나 작업 순서를 고르지는 않는다.

## 자기회귀 VLA에서는 어떻게 연결될까?

자기회귀 방식의 VLA는 영상·언어를 조건으로 앞서 생성한 행동 토큰을 참고해 다음 행동 토큰을 예측한다. 학습 때 미래의 정답 행동이 새어 들어오지 않도록 행동 시퀀스에 causal mask를 적용한다. 영상·언어 토큰끼리 또는 행동과 상호 참조하는 구체적인 범위는 모델 설계를 따른다.

예를 들어 세 번째 행동 토큰을 예측한다면, 허용된 관측·지시와 앞의 두 행동 토큰은 참고하지만 세 번째 정답과 이후 토큰은 보지 못한다. 앞선 출력과의 의존성을 학습할 수 있지만, 토큰 하나가 반드시 완결된 동작 하나에 대응하는 것은 아니다. 위치·회전·그리퍼 같은 행동 성분을 각각 토큰화할 수도 있다.

‘연속적인 로봇 행동’과 ‘연속값 출력’은 구분해야 한다. 연속값을 이산 토큰으로 바꿔 예측한 뒤 복원하는 모델도 있고, 연속값을 직접 내는 모델도 있다. 모든 VLA가 자기회귀 생성이나 같은 마스크를 쓰는 것은 아니다.

Causal Attention은 학습 중 정보 누출을 막고 앞선 출력에 근거한 생성을 가능하게 한다. 움직임의 부드러움·충돌 회피·안전성을 보장하지는 않는다. 실제 실행에는 행동 복원, 좌표·단위 변환, 로봇 한계 검사와 최신 관측에 따른 피드백이 필요하다.
